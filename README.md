# Welcome to my Portfolio!

Live at [anthonyhana.com](https://anthonyhana.com). Built with React + TypeScript + Vite + Tailwind v4.

```bash
npm install
npm run dev      # local dev server
npm run build    # type-check + production build to ./dist
npm run deploy   # build and publish ./dist to the gh-pages branch
```

The previous version of the site is archived in [`v1/`](v1/). It's no longer deployed; don't run
`npm run deploy` from inside it, since that would replace the live site with the old one.
